# Changelog

All notable changes to Soniq are listed here. The project follows [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-10-17

First public release.

### Added
- Volume boost up to 200% with a peak limiter.
- Per-app volume, mute and left/right balance.
- Sound effects: Bass Boost, Party, Underwater, Concert, Next Room, In the Car, Radio, 3D Wide, Vocal, Night and Cinema, with intensity, bass and treble.
- Output device switcher.
- Microphone level, input switcher and "Keep this microphone".
- Headphone and AirPods test: left/right, stereo sweep, frequency sweep, bass response and phase check.
- In-panel settings to hide sections and launch at login.
- Native SwiftUI interface with Liquid Glass on macOS 26.
